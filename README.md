# כתבי כמויות ואומדנים – משרד טיקטין

תוכנה לעריכת כתבי כמויות, אומדנים והשוואת הצעות קבלנים (ייבוא/ייצוא SKN, Excel, PDF, Word).

- כאן נמצא הקוד בלבד. המחירונים והנתונים נמצאים בשרת מאובטח, והגישה אליהם רק לעובדי המשרד עם סיסמה אישית.
- הכתבים עצמם נשמרים במחשב של המשתמש.
- קישור ישיר לפרויקט לפי מספר ISO: `?iso=12345`
